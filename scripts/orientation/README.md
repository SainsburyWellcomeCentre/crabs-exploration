## Crab orientation: ellipses from masks, and manual labels to check them

1. `generate_masks_from_bboxes.py`: script to generate SAM2 masks and ellipse parameters from annotated boxes.
2. `create_labelling_package.py`: script to build a package to label the orientation of each crab.
3. `annotate_crabs_orientation_manual.py`: a script to set up napari to label crab orientation.

Steps 2 and 3: see [guides/ManualAnnotationOrientation.md](../../guides/ManualAnnotationOrientation.md).
